## ⚡ Highlights
* **Native Jupyter Notebooks** (`ipynb.nvim` + `snacks.nvim`): Edit and run `.ipynb` files with kernel execution, cell navigation, and outputs.
* **Modern Database IDE** (`vim-dadbod` + `vim-dadbod-ui` + `blink.cmp`): Visual database drawer, table schema browsing, query runner (`<leader>r`), and column autocompletion.
* **Ultra-Fast Completion** (`blink.cmp`): Zero-latency LSP, path, buffer, snippet, and SQL database completions.
* **Smart Navigation**: Seamless Tmux navigation (`<Ctrl + h/j/k/l>`), Flash jump (`ss`), and Oil directory editing (`-`).
* **Ergonomic Deletion**: Black-hole deletions (`dd` in Normal mode, `d` in Visual mode) so your clipboard stays clean.
